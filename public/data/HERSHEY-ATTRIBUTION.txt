Ink & Hour — original Hershey centerline data

The bundled src/writing/fonts.json contains only these subsets of the ORIGINAL
Hershey JSON dataset distributed by techninja/hersheytextjs:

  correspondence -> scripts, "Script 1-stroke"
  print          -> futural, "Sans 1-stroke"

Each subset retains the first 94 original character records without changing
their d (absolute M/L centerline path) or o (advance) values. These correspond
to ASCII 33 through 126, indexed by charCode - 33. ASCII space and line breaks
are layout operations, not glyphs. The nonprintable 95th record is not bundled.
No fonts from the separately licensed SVG collection are included.

Original engraving font data: Dr. A. V. Hershey. JSON port via the EMSL / Evil Mad
Scientist Hershey Text Inkscape data and techninja's Hershey Text JS project.
Upstream renderer code and other fonts are not bundled.

Spacing reference:
https://raw.githubusercontent.com/techninja/hersheytextjs/master/lib/hersheytext.js
The upstream original-Hershey renderer advances by o * 1.68 and gives a space
10 font units. Ink & Hour uses that advance as a lower bound, also checking
actual stroke extents and adding small style-dependent tracking.

Reproduce from the project root using Node 23.11 or later:
node src/writing/generate-fonts.mjs
The generator verifies the full source hash before writing the same subset.

Rendering and limits:
These are ordered engraving centerlines, not letter outlines or a recording of
someone's hand. Every original M and every character boundary remains a real
pen lift. Short quadratic rounding softens polylines without crossing lifts or
expanding the original bounds; sharp print corners remain sharp. Some original
punctuation and script numerals contain multiple close strokes.
Supported input is printable English ASCII, spaces and line breaks. CRLF and CR
normalize to LF. Accents, smart quotes, emoji, tabs and other non-ASCII input
produce an explicit validation error rather than substitution.
The maximum is 420 characters after newline normalization; the finite sheet can
fill sooner, depending on glyph widths and line breaks. Overflow fails the
entire layout rather than cropping text. There is no pagination or shaping for
other writing systems. At a normal 780 by 1040 sheet, correspondence fits up to
13 lines and print up to 15 lines. Space at an automatic line boundary serves
as the line break; explicit newlines, including empty lines, consume a line.

Nib response and pace are gentle artistic interpretations, not manufacturer
physics: broad uses a fixed 45-degree chisel, fine is restrained, and flex reacts
mainly to downstroke pressure with slightly more response for a pointed dip pen.
